# Bank Management System

## About the Project
A desktop-based Bank Management System developed using Java Swing and MySQL. The application is designed to manage basic banking operations through a graphical user interface.

## Features
- User registration through multiple signup forms
- Login using card number and PIN
- Account information management
- Cash deposit
- Cash withdrawal
- Fast cash withdrawal
- Balance enquiry
- PIN change
- Mini statement and transaction history

## Technologies Used
- **Programming Language:** Java
- **GUI:** Java Swing, AWT
- **Database:** MySQL
- **Database Connectivity:** JDBC
- **IDE:** NetBeans

## Database Setup
1. Install MySQL Server and MySQL Workbench.
2. Open the SQL script included in this repository.
3. Review the script before executing it.
4. Execute it to create the `bankmanagementsystem` database and its tables.
5. Configure the database connection in `Conn.java`.

**Note:** The provided SQL script drops and recreates the database. Running it again deletes existing data.

## Prerequisites
- Java Development Kit (JDK)
- MySQL Server
- MySQL Connector/J JDBC driver
- NetBeans IDE

## How to Run
1. Clone or download this repository.
2. Open the project in NetBeans.
3. Add the MySQL Connector/J driver to the project libraries.
4. Configure your MySQL connection settings.
5. Execute the database setup script if required.
6. Run the application's main class.

## Security Notice
Do not commit database passwords, real card details, PINs, or personal customer data.
